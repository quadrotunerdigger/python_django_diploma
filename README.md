# Megano — Интернет-магазин

Дипломный проект на Django. Платформа интернет-магазина с каталогом товаров,
корзиной, оформлением заказов, фиктивной оплатой и личным кабинетом.

## Развёртывание проекта

```bash
# 1. Клонировать репозиторий
git clone <url>
cd python_django_diploma

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Собрать и установить фронтенд-пакет
pip install setuptools
cd diploma-frontend
python setup.py sdist
pip install dist/diploma-frontend-0.6.tar.gz
cd ..

# 5. Применить патчи фронтенда
python patch_search.py     # поиск из шапки сайта
python patch_payment.py    # обработка ошибок оплаты + кнопка генерации счёта

# 6. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — указать SECRET_KEY

# 7. Раскомментировать frontend в settings.py и urls.py
# В megano/settings.py: раскомментировать "frontend" в INSTALLED_APPS
# В megano/urls.py: раскомментировать path("", include("frontend.urls"))

# 8. Применить миграции
python manage.py migrate

# 9. Загрузить демо-данные
python manage.py loaddata demo_data

# 10. Привязать изображения товаров (если папка media/ присутствует)
python manage.py link_images

# 11. Запустить сервер
python manage.py runserver 0.0.0.0:8000
```

**Важно:** при переустановке фронтенд-пакета (`pip install diploma-frontend`)
необходимо повторно применить оба патча (шаг 5).

## Альтернативный способ заполнения данных

Вместо `loaddata` можно сгенерировать демо-данные командой:

```bash
python manage.py populate_demo
python manage.py link_images
```

### Изображения товаров

Изображения хранятся в `media/products/<Категория>/<Подкатегория>/<Товар>/preview/` и `.../images/`.
Они не входят в фикстуру — необходимо наличие папки `media/` с изображениями
и выполнение команды `python manage.py link_images`.

## Поиск

Поиск осуществляется через строку поиска в шапке сайта. Поддерживается:
- Поиск по названию товара (регистронезависимый)
- Поиск по названию категории (например, «чайник» найдёт товары из категории «Чайники»)
- Поиск по родительской категории (например, «комплектующие» найдёт все товары из «Компьютеры и комплектующие»)

## Административный раздел

Доступен по адресу `/admin/`. Позволяет управлять:
- Товарами (с инлайнами для изображений, характеристик, отзывов)
- Категориями (с вложенностью до 2 уровней)
- Заказами (с позициями заказа)
- Пользователями и профилями
- Скидками, тегами, настройками сайта

Реализовано мягкое удаление для товаров, категорий и заказов.
Галки «ограниченный тираж» и «удалён» редактируемы прямо из списка товаров.

## Фиктивная оплата

Логика оплаты (по ТЗ):
- Номер карты/счёта: ровно 8 цифр
- Чётный номер, не заканчивающийся на 0 → оплата успешна
- Чётный номер, заканчивающийся на 0 → случайная ошибка оплаты
- Нечётный номер → ошибка валидации
- При выборе «Онлайн со случайного чужого счёта» отображается кнопка «Сгенерировать случайный счёт» (генерирует валидный 8-значный номер)
- Статус оплаты и текст ошибки отображаются на странице заказа
