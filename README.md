# Megano — Интернет-магазин

Дипломный проект на Django. Платформа интернет-магазина с каталогом товаров,
корзиной, оформлением заказов, фиктивной оплатой и личным кабинетом.

## Развёртывание проекта

```bash
# 1. Клонировать репозиторий
git clone <url>
cd python_django_diploma

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Собрать и установить фронтенд-пакет
cd diploma-frontend
pip install setuptools
python setup.py sdist
pip install dist/diploma-frontend-0.6.tar.gz
cd ..

# 5. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — указать SECRET_KEY

# 6. Применить миграции
python manage.py migrate

# 7. Загрузить демо-данные (фикстура)
python manage.py loaddata demo_data

# 8. Запустить сервер
python manage.py runserver 0.0.0.0:8000
```

После `loaddata demo_data` в системе доступны:

|---------|--------|---------------|
| admin   | admin  | Администратор |
| buyer1  | 123456 | Покупатель    |
| buyer2  | 123456 | Покупатель    |

### Данные

- **16 товаров** с изображениями (preview + дополнительные), характеристиками и отзывами
- **12 категорий** (3 родительские + 9 подкатегорий, вложенность 2 уровня)
- **8 тегов** для фильтрации
- **7 скидок** с датами действия
- **3 демо-заказа** от покупателей
- **Настройки сайта** (стоимость доставки, порог бесплатной доставки)

### Изображения товаров

Изображения хранятся в `media/products/<Категория>/<Товар>/preview/` и `.../images/`.
Они не входят в фикстуру — необходимо наличие папки `media/` с изображениями.

## Административный раздел

Доступен по адресу `/admin/`. Позволяет управлять:
- Товарами (с инлайнами для изображений, характеристик, отзывов)
- Категориями (с вложенностью до 2 уровней)
- Заказами (с позициями заказа)
- Пользователями и профилями
- Скидками, тегами, настройками сайта

Реализовано мягкое удаление для товаров, категорий и заказов.

## Фиктивная оплата

Логика оплаты (по ТЗ):
- Номер карты/счёта: максимум 8 цифр, должен быть чётным
- Чётный номер, не заканчивающийся на 0 → оплата успешна
- Чётный номер, заканчивающийся на 0 → случайная ошибка оплаты
