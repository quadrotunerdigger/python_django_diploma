# Чек-лист проверки требований ТЗ — Megano

## Технические требования

- [x] **Django-проект, «легкопереносимый»**
  → `git clone` → `cp .env.example .env` → `python manage.py migrate` → `python manage.py runserver 0.0.0.0:8000`

- [x] **Админпанель через Django Admin**
  → Открыть `http://127.0.0.1:8000/admin/`, войти admin / admin

- [x] **Миграции корректные (apply + rollback)**
  → `python manage.py migrate shopapp zero` — откатит все миграции
  → `python manage.py migrate` — применит заново без ошибок

- [x] **Data-миграция: администратор, роли пользователей**
  → После `migrate` автоматически создаются: суперпользователь admin, группы «Администратор» и «Покупатель»
  → Проверить: `http://127.0.0.1:8000/admin/auth/group/` — 2 группы

- [x] **Фикстура данных: покупатели, товары, категории, цены, заказы, скидки**
  → `python manage.py loaddata demo_data` — загрузит 30 товаров, 19 категорий, 3 покупателей (buyer1/buyer2/buyer3, пароль 123456), заказы, скидки, отзывы
  → Проверить: `http://127.0.0.1:8000/admin/shopapp/product/` — 30 товаров

- [x] **README.md с шагами развёртывания**
  → Файл `README.md` в корне проекта, содержит пошаговую инструкцию

- [x] **Файл .env для настроек**
  → Файл `.env.example` с переменными `DJANGO_SECRET_KEY`, `DJANGO_DEBUG`, `DJANGO_ALLOWED_HOSTS`

## Оплата

- [x] **Поле ввода номера карты/счёта (до 8 цифр)**
  → `http://127.0.0.1:8000/payment/{id}/` — поле «Номер карты» + кнопка «Оплатить»

- [x] **Валидация: номер чётный, не длиннее 8 цифр**
  → Ввести нечётный номер (например 1234567) → ошибка

- [x] **Чётный и не заканчивается на 0 → оплата подтверждена**
  → Ввести 12345678 → оплата успешна, статус заказа «Оплачен»

- [x] **Чётный и заканчивается на 0 → случайная ошибка оплаты**
  → Ввести 12345670 → ошибка оплаты, статус «Ошибка оплаты» + текст ошибки

- [x] **Статус оплаты и текст ошибки отображаются в истории заказов**
  → `http://127.0.0.1:8000/history-order/` — столбец «Статус», при ошибке — текст ошибки в деталях заказа

- [x] **Редактирование профиля: ФИО, телефон, email, пароль, аватар**
  → Изменить ФИО → нажать «Сохранить» → данные обновлены
